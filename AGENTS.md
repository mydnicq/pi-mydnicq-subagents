# AGENTS.md

Working rules for coding agents in this repository.

1. **Be concise.** Short answers, tight lists, minimal prose.
2. **Agent files are self-contained.** There are no global overrides and no shared defaults — each agent file carries all the config data required to run that agent independently.
3. **Use the project terminology.** Canonical terms are defined in `TERMINOLOGY.md`; consult it before naming code, docs, or UI copy. Never edit `TERMINOLOGY.md` without explicit user approval — propose new terms and wait for the user to add them.
4. **Keep the surface list current.** When adding, renaming, or removing a tool or command, update the "Tools and commands" section in `README.md`.
